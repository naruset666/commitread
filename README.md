สรุปฟีเจอร์ที่คุณทำ
1. Tournament CRUD API
พัฒนาระบบจัดการการแข่งขัน Tournament
- สร้าง Tournament
- ดูข้อมูล Tournament
- แก้ไขข้อมูล Tournament
- ลบ Tournament
- ตรวจสอบข้อมูลก่อนบันทึก เช่น วันที่แข่งขัน ชื่อซ้ำ และรูปแบบการแข่งขัน
2. FFWS Placement Points
พัฒนาระบบคะแนนอันดับสำหรับการแข่งขัน Free Fire แบบ POINTS
- สร้างคะแนนอันดับเริ่มต้นอัตโนมัติเมื่อสร้าง Tournament แบบ POINTS
- กำหนดคะแนนอันดับ 1–12 ตามกติกา FFWS
- ใช้ Repository จัดเก็บและค้นหาคะแนนอันดับ
- รองรับแนวทางการแก้ไขคะแนนก่อนเริ่มการแข่งขันตามข้อกำหนดของระบบ
คะแนนเริ่มต้นคือ 12, 9, 8, 7, 6, 5, 4, 3, 2, 1, 0, 0
3. TournamentTeam และกฎการเข้าร่วมแข่งขัน
พัฒนาส่วนที่เกี่ยวข้องกับการนำทีมเข้าร่วม Tournament และตรวจสอบเงื่อนไข เช่น
- ตรวจสอบว่าทีมและ Tournament มีอยู่จริง
- ตรวจสอบสถานะ Tournament
- ป้องกันทีมสมัครซ้ำ
- ตรวจสอบว่าเกมของทีมตรงกับเกมที่จัดแข่งขัน
- ตรวจสอบจำนวนผู้เล่นขั้นต่ำและข้อจำกัดคะแนน
- ตรวจสอบเงื่อนไขวันที่แข่งขัน
ส่วนนี้มีการใช้แนวคิด Chain of Responsibility เพื่อแยกกฎการตรวจสอบออกเป็นแต่ละ Rule
4. การทดสอบและปรับปรุงระบบ
- เขียนและปรับปรุง Unit Tests
- ตรวจสอบการทำงานของ Service และกฎต่าง ๆ
- ทดสอบระบบหลังแก้ไขโค้ด
- ทำงานร่วมกับการรวมโค้ดจาก develop
จากข้อมูลการทำงานล่าสุดที่เราเคยตรวจสอบ มีการทดสอบผ่าน 57/57 tests ในช่วงหนึ่งของงาน

ผมรับผิดชอบการพัฒนาระบบ Tournament ในโปรเจกต์ Spring Boot โดยมีฟีเจอร์หลักคือ Tournament CRUD API สำหรับสร้าง ดู แก้ไข และลบการแข่งขัน พร้อมตรวจสอบเงื่อนไขข้อมูล นอกจากนี้ยังพัฒนาระบบ FFWS Placement Points ที่สร้างคะแนนอันดับเริ่มต้นอัตโนมัติสำหรับการแข่งขันแบบ POINTS และทำงานในส่วน TournamentTeam ซึ่งเกี่ยวข้องกับการเข้าร่วมแข่งขันและการตรวจสอบกฎของทีม รวมถึงเขียน Unit Tests เพื่อทดสอบการทำงานของระบบ
